# Automobile Insurance Complaints Analysis

## Project Overview
This project focuses on analyzing automobile insurance complaints using SQL and Power BI. The objective is to explore complaint data, identify key insights, and present findings through an interactive dashboard.

## Tools Used
- SQL
- Microsoft Power BI
- Microsoft Word
- Microsoft PowerPoint

## Project Details
- Total Records: 1,358
- Total Complaints: 35,919
- Dashboard: 4 KPI cards and a pie chart

## Project Objectives
- Analyze automobile insurance complaint data.
- Retrieve and analyze data using SQL queries.
- Identify important trends and patterns.
- Create an interactive Power BI dashboard.
- Present key findings through visualizations.

## Files Included
- `Auto_insurance_dataset.sql` – SQL queries and analysis.
- `Automobile Insurance Complaints Analysis Project.docx` – Project documentation.
- `Automobile Insurance Complaints Analysis.pptx` – Project presentation.
- `Automobile Insurance Dashboard.pbix` – Power BI dashboard.

## Key Learning Outcomes
- Practiced SQL-based data analysis.
- Developed skills in Power BI dashboard creation.
- Learned to present data insights through visualizations.
- Improved data analysis and reporting skills.
